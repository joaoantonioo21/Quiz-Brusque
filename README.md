# Quiz Brusque

## Sobre o projeto

O Quiz Brusque é um jogo educativo desenvolvido em HTML, CSS e JavaScript com o objetivo de ensinar curiosidades sobre a cidade de Brusque de forma interativa e divertida.

O jogador inicia preenchendo:
- nome
- escola
- idade

Depois responde perguntas escolhendo imagens como alternativa.

Ao final do jogo, o sistema mostra:
- pontuação
- feedback do desempenho
- opção de jogar novamente

---


## Funcionalidades

- Tela inicial
- Sistema de perguntas
- Alternativas com imagens
- Contagem de pontuação
- Feedback final
- Botão para reiniciar o jogo
